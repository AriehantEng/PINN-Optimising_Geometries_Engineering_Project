# Falsifiability matrix (SPEC v2, S5)

Generated by `python -m src.report --falsifiability`.
**Regenerate on every ansatz change** -- a stale matrix is the silent
disarming this exists to prevent, and `tests/test_sentinels.py` fails
if this file does not match the code.

A check is classified by running it on an UNTRAINED, randomly
initialised network at five seeds:

* `LIVE` - fails at every seed, so the check bites.
* `WEAKENED` - passes at some seeds, so it partly measures the ansatz.
* `VACUOUS` - passes at every seed, so it measures the ansatz and not
  the trained solution.

Columns: `vp-*` velocity-pressure with the soft/hard pressure gauge;
`psi-*` the psi-omega system under the cubic/sinusoidal lift.

| check                      | vp-soft    | vp-hard    | psi-cubic  | psi-sin    |
|----------------------------|------------|------------|------------|------------|
| wall no-slip               | VACUOUS    | VACUOUS    | VACUOUS    | VACUOUS    |
| test 1  u relative L2      | LIVE       | LIVE       | LIVE       | LIVE       |
| test 2  max |v*|           | LIVE       | LIVE       | LIVE       | LIVE       |
| test 3  mass conservation  | LIVE       | LIVE       | VACUOUS    | VACUOUS    |
| inlet profile              | LIVE       | LIVE       | LIVE       | LIVE       |
| pressure gauge at outlet   | LIVE       | LIVE       | LIVE       | LIVE       |
| CONTROL always-true        | VACUOUS    | VACUOUS    | VACUOUS    | VACUOUS    |
| CONTROL always-false       | LIVE       | LIVE       | LIVE       | LIVE       |

## Degenerate targets

A check can be `LIVE` -- an untrained network fails it -- and still be
nearly free, because the ansatz places the correct answer at a single
point the optimiser can reach exactly. Sampling at the initialisation
distribution cannot see that, so this probes it directly by zeroing the
output layer, i.e. removing the network's contribution entirely.

Checks that PASS with no network contribution at all:

* `vp-soft`: wall no-slip, test 2  max |v*|, pressure gauge at outlet
* `vp-hard`: wall no-slip, test 2  max |v*|, pressure gauge at outlet
* `psi-cubic`: wall no-slip, test 1  u relative L2, test 2  max |v*|, test 3  mass conservation, inlet profile
* `psi-sin`: wall no-slip, test 2  max |v*|, test 3  mass conservation

Read `psi-cubic` carefully: essentially the whole Case A suite passes
with the network removed, because the cubic lift's derivative IS the
Case A solution. Its accuracy must never be quoted as a result.

`test 2  max |v*|` is degenerate in EVERY column: the zero field passes
it. It cannot distinguish a correct solution on its own and is only
meaningful conjoined with test 1.

## Untested properties

These are `VACUOUS` in every column, so the suite does not test
them at all:

* wall no-slip
* CONTROL always-true

## Degenerate configurations (not detectable from accuracy alone)

A configuration is degenerate when the correct answer is something the ansatz
already produces, so the network is not being tested. Accuracy does not reveal
this -- the cubic lift scored 1.10e-06 against the sinusoidal lift's 7.38e-07,
i.e. slightly WORSE, despite its answer being exactly representable. Only the
structure reveals it.

| Configuration | Why it is vacuous | Guard |
|---|---|---|
| `model.lift: cubic` (psi-omega) | psi_base' = (3Q/4)(1 - y^2) IS the exact Case A profile, so the correct answer is N_psi = 0 | `lifts.DEGENERATE_LIFTS`; reported by the sentinel matrix |
| `physics.inlet_sharpness: 1` (Case B) | U0 = 1 and the profile is 1 - y^2, the developed solution, so Case B starts developed: no entrance region, zero entrance length | `inlets.DEGENERATE_SHARPNESS`; **refused by config** so it cannot be reported |
| test 3 under psi-omega | continuity holds by construction, so mass conservation cannot fail | drift < 1e-12 reports VACUOUS, never PASS |
| test 2 (`max |v*|`) in every formulation | the zero field passes it | reported as degenerate in the matrix |

The inlet case is refused outright rather than merely flagged, because unlike
the cubic lift it has no legitimate use: the cubic lift is a useful machinery
check, whereas a Case B that is already developed tests nothing at all.
